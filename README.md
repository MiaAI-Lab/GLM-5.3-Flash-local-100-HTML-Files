# GLM 5.3 Flash (local) · 100 HTML Files

One hundred self-contained visual studies — generative art, physics, typography, instruments,
interfaces and scenes — hand-written page by page by a team of artist agents running
**GLM 5.3 Flash (local)**.

Every piece is a **single offline HTML file**: inline CSS, inline JavaScript, system fonts,
canvas and inline SVG only. No CDN, no external fonts, no images, no libraries — open any file
in a browser and it just works.

Each HTML has a matching `.txt` companion containing the full creative prompt (title,
description, techniques, interaction model and the recreation prompt).

## Browse the gallery

**[→ Open the indexed gallery with screenshots](https://miaai-lab.github.io/GLM-5.3-Flash-local-100-HTML-Files/)**

The index shows a screenshot of every piece, links each page, and embeds the original
generation prompt behind a *Prompt* toggle on every card.
