TITLE: Aurora Glass Studio
DESCRIPTION: A frosted-glass creative-studio dashboard floating over a living aurora night sky. Behind everything, layered ribbon gradients in cyan, violet, mint and pink drift and breathe across deep indigo, dotted with a slowly twinkling canvas starfield. In front, translucent glass panels — backdrop blur, hairline white borders, inner top highlights — carry a huge display metric called Studio Pulse, a glowing dual-pass line chart with hover crosshair and tooltips, four stat tiles with seeded sparklines, a channel-mix bar block, a timestamped pulse log, and a slim vertical glass nav rail with tooltips. The signature moment: every glass card tilts in 3D toward the cursor with a moving specular glare while the aurora breathes behind it.
TECHNIQUES:
- Layered aurora made of blurred conic and radial gradient ribbons animated at long, offset durations, blended with screen mix-blend-mode
- Canvas starfield with seeded pseudo-random star placement and per-star twinkle phase
- Frosted glass primitive: backdrop-filter blur plus saturation, 1px rgba white borders, inset highlights, layered drop shadow
- 3D card tilt driven by pointer position via CSS custom properties (--rx, --ry) and a radial glare follow light (--gx, --gy)
- Canvas line chart drawn twice for glow then crispness, quadratic-smoothed, with animated data shifting and an eased counting metric
- Seeded deterministic sparklines rendered per tile with accent-colored gradients
- Staggered keyframe animations with prefers-reduced-motion fallback to a calm static sky
INTERACTION:
- Moving the cursor over any glass panel tilts it toward the pointer and shines a glare highlight; leaving recenters it
- Hovering the chart shows a dashed crosshair, a dot, and a tooltip with value and offset time; range buttons (1H / 24H / 7D) swap datasets with an eased count-up of the headline metric
- Data advances on a timer so the live head dot pulses and the metric keeps ticking; nav rail buttons show tooltips and a glowing active indicator
- Fully keyboard-reachable controls with visible focus rings; layout collapses to a bottom nav bar on phones and a single column on tablets
PROMPT:
Design a single-page, single-file HTML dashboard titled "Aurora Glass Studio". The page is a frosted-glass control room floating in a night sky. Background: deep indigo base (#0b1026 darkening to #070b1c at the bottom) with four huge blurred ribbon blobs — conic and radial gradients in cyan #22d3ee, violet #a78bfa, mint #34d399 and pink #f472b6 at 15–30% opacity — that slowly translate, scale and breathe over 30–45 second alternating loops, blended with screen mode. A repeating-linear-gradient "curtain" of faint diagonal light streaks is masked to the upper sky, and a canvas starfield of ~60–170 seeded stars twinkles with individual phase offsets. A radial vignette darkens the corners.

Layout: a slim vertical nav rail on the left (84px, glass background, 1px right border) holding an italic serif "Ag" monogram tile, six inline-SVG icon buttons with hover tooltips sliding from the right and an active state with a glowing gradient indicator bar; the main stage holds a top bar (breadcrumb, pill search field with focus glow, monospace clock, gradient avatar), a hero row, a four-tile metrics row, a two-card detail row, and a quiet footer.

Hero: left card-free copy block with a pulsing green live-dot eyebrow "LIVE · STUDIO PULSE · Q4", a giant gradient-clipped numeral (clamp 3.4rem–6.6rem, weight 800, tracking −0.045em) reading a live "events / minute" value, a serif italic unit label, an up/down chip, and a short note. Right: a glass chart card with a Throughput header, a pill range switcher (1H/24H/7D), and a canvas line chart: grid lines, right-aligned monospace axis labels, a cyan-to-violet gradient stroke drawn twice (wide blurred glow pass, then 2px crisp pass), a soft gradient area fill, a pulsing live head dot, and a hover crosshair with a glass tooltip showing value and "−N min/h" time. Data is generated from a seeded sine-plus-noise series and scrolls leftward every ~2.4s while the headline number eases to match.

Tiles: Sessions 2,847, Render farm 96.2%, Queue 38 jobs, Error rate 0.42% — each with an uppercase tracked label, a small icon chip, a delta line, and a seeded accent-colored sparkline canvas. Detail row: a Channel mix card with four glowing gradient progress bars (Motion 34%, Brand 26%, Web 22%, Print 18%) that animate wide on load; a Pulse log card listing five timestamped events with colored uppercase tags (web, render, team, brand).

Glass recipe for every panel: linear-gradient rgba(255,255,255,.10)→.045 fill, backdrop-filter blur(18px) saturate(1.45), 1px rgba(255,255,255,.16) border, inset 0 1px 0 rgba(255,255,255,.28) top highlight, 0 24px 60px black shadow, 20px radius. Signature moment: on mouse move each panel tilts in 3D toward the cursor (perspective 1000px, about ±7–9 degrees) while a radial glare follows the pointer across its surface, all driven by CSS custom properties updated from JS.

Typography: system-ui with tight-tracked tabular numerals for data; ui-serif Georgia italic for the wordmark and unit labels; ui-monospace for the clock, axis labels and mix values. Text color #eef2ff with dimmer rgba tiers. Custom selection color (violet tint), thin rounded translucent scrollbar, cyan focus rings. Responsive: hero and deck collapse to one column under 1060px; under 640px the rail becomes a fixed bottom bar with tooltips flipping upward and the active dot moving under the icon. prefers-reduced-motion freezes the sky, tilt, and pulses, rendering one calm static frame of everything. No images, no fonts, no network — every visual is CSS gradient, inline SVG or Canvas 2D.
