TITLE: Tape Reader
DESCRIPTION: A vintage stock-ticker terminal in a putty housing. An amber CRT shows THE COMPOSITE index with a sparkline chart, a five-line watchlist with per-ticker mini-sparks and green/red price flashes, a running tick counter and a sweeping scanline — all on fictional tickers (BRSS, LUME, PHOS, TAPE, KETL). Below the glass, a real paper tape prints rows of symbol, time, price and delta, feeding from a slot; drag it down to tear it off and receive a session stats receipt with a zig-zag torn edge. A crash button floods the board red, blinks an alarm overlay and sounds a klaxon; the tape never stops feeding. Keyboard shortcuts: P pause, C crash, R restore, T tear, 1–5 select.
TECHNIQUES:
- Amber CRT rendering on canvas: vignette + scanline overlays, stepped flicker layer, a slow scanline sweep drawn per frame, and amber/dim text tiers via a text helper
- Simulated market: five fictional tickers with drift and volatility, tick engine at 2.2 tps, decaying flash values, 90-point history per ticker for mini-sparklines, and a rebased composite index
- Paper tape renderer: cream gradient paper with printed stripe ghosts, scrolling rows driven by sub-row offset, sprocket hole chains on both edges, a dashed tear line, and green/red delta inks
- Tear interaction: pointer-drag threshold triggers a CSS rip (translate + rotate + fade), then a receipt dialog with a zig-zag bottom edge built from two 45° gradient strips
- Crash state: red flood overlay with blinking alarm, all rows flashing red, doubled volatility drift, and a two-tone square-wave klaxon (WebAudio, user-initiated)
- Housing craft: putty machine shell with inset shadows, vent grille, dark CRT bezel, and press-down deck buttons with hard shadows
INTERACTION:
- The board and tape run continuously; keyboard P pauses the feed, C triggers the crash (red flood + alarm + halted note), R restores calm, T tears the tape, 1–5 select a watchlist row (highlight box), Escape closes the receipt
- Dragging the tape down past 34px rips it: the strip drops and fades, and a rotated session receipt prints ticks, crashes, session high/low, composite level and tapes torn — fold it away or click outside to dismiss
- Watchlist rows flash green or red on each tick and carry mini sparklines; the index chart writes itself rightward with a live head dot
- Reduced-motion mode renders on a 1.2s interval without the sweep/flicker/rip transitions
PROMPT:
Build a single-file HTML vintage stock-ticker terminal titled "TAPE READER — Market Terminal 089". Housing: a centered machine shell (max 1180px) — putty gradient with inset highlights, a vent grille strip on top, a dark CRT bezel wrapping the screen, a control deck row, and a tape bay at the bottom feeding from a dark slot; press-down deck buttons with hard shadows; a mono foot plate reading "TAPE READER · THE GALLERY OF 100 · ROOM 89 · EVERY QUOTE ON THIS TAPE IS FICTION WEARING A SUIT".

CRT (clamp 240–420px tall): draw on canvas — header "THE COMPOSITE — 5 ISSUES" with the live index value and ▲/▼ change at right (green/red); a bordered sparkline chart (~42% width) writing itself rightward with a head dot; a WATCHLIST panel listing five fictional tickers (BRSS Brassworks & Sons, LUME Lumen Filament Co., PHOS Phosphor Displays, TAPE Tape & Register, KETL Kettle Steam Union), each row showing symbol, price (flashing green/red per tick), percentage change, and a tiny inline sparkline; a bottom status line "TAPE RUNNING · TICKS N · CRASHES N" (plus "TRADING HALTED" during crash); a slow diagonal scanline sweep and stepped flicker above everything, under a curved vignette + scanline overlay. Tape bay: a paper-tape canvas (118px) — cream gradient with faint print stripes, sprocket holes chained down both edges, and scrolling printed rows (symbol, HH:MM:SS, price ± delta in green/red ink) that advance in lockstep with market ticks, with a dashed tear line at the bottom edge and a hint "DRAG THE TAPE DOWN TO TEAR". Dragging down past ~34px rips it: the strip translates 90px down, rotates 3°, fades — then a session receipt slides in: a rotated cream card with a zig-zag torn bottom edge (two crossing 45° gradient strips), a dashed-rule header "SESSION RECEIPT — TAPE READER 089", a dotted-row table (session ticks, crashes triggered, session high, session low, composite now, tapes torn), fine print about fictional markets, and a "FOLD IT AWAY" button; the tape respawns after ~1.4s.

Signature moment: the crash — the CRASH button (or C) floods the board red with a blinking alarm overlay, all flashes turn red, volatility doubles, and a two-tone square-wave klaxon blasts twice (WebAudio only on user action); RESTORE CALM (or R) returns the amber world. Keyboard shortcuts throughout: P pause tape, C crash, R restore, T tear, 1–5 select, Escape dismiss receipt.

Engine details: 2.2 ticks per second, per-ticker drift and volatility with decaying flash values, 90-point histories, a rebased composite average, and reduced-motion rendering at 1.2s intervals with no sweep or flicker. Responsive under 640px (deck note hides, board and tape shrink). No network, no images — the board, tape and paper are all canvas, the alarm is an oscillator.
