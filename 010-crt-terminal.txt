TITLE: TERMINAL/84
DESCRIPTION: A full-screen CRT terminal emulator styled as a 1984 phosphor workstation: a dark bezel with a curved-glass vignette, scanlines, aperture grille, slow flicker and a rolling refresh bar over near-black green screen. A boot sequence types itself out with per-character animation (skippable with Enter), then hands over to a real keyboard-driven prompt with command history, TAB autocomplete, and per-character typed responses. Commands include help, about, gallery (an ASCII room index of the collection), matrix (a glyph rain overlay toggled on and off), theme (switch phosphor green to warm amber), listen (a 60Hz mains hum synthesized with WebAudio), status, whoami, date, echo, clear, a sudo joke, and a konami easter egg with ASCII art.
TECHNIQUES:
- CRT atmosphere layered in pure CSS: inset glass shadow with faint phosphor bloom, radial curved-screen vignette, repeating scanline and aperture-grille gradients multiply-blended, stepped opacity flicker, and a slow rolling brightness bar
- Phosphor identity through text-shadow glow tiers (hi/soft/dim/faint) plus an inverse-video class; theme swap via CSS custom properties on a body.amber class
- Typed output engine: a queue of jobs rendered per-character with an rAF accumulator (characters-per-second control), so every response clatters like a teletype
- Matrix rain as a dynamically injected canvas overlay with three-depth glyph trails that recolor with the active phosphor theme
- WebAudio mains hum: 60Hz + 120Hz sine pair with a slow gain ramp, created only on user toggle; matrix runs on its own cancellable rAF
- Command line: keydown capture, input buffer, history stack with ArrowUp/Down, longest-common-prefix TAB autocomplete, Ctrl+L clear, Ctrl+C interrupt, and a hidden mobile input shim
INTERACTION:
- The keyboard is the interface: type commands at the blinking block cursor, Enter executes, TAB completes, arrows walk history, Ctrl+L wipes the screen, Ctrl+C interrupts the current line
- The boot sequence types out memory tests and phosphor checks (press Enter or Space to skip ahead), then the prompt appears
- 'matrix' toggles the glyph rain over the tube; 'theme amber'/'theme phosphor' (or the bezel button) swaps the phosphor chemistry; 'listen' or the Hum button energizes a 60Hz mains hum
- The status line winks through idle states every 9 seconds; power strip buttons hover with phosphor washes; touch devices get a hidden input shim to summon the keyboard
PROMPT:
Build a single-file HTML full-screen CRT terminal titled "TERMINAL/84 — Phosphor Workstation". The tube: near-black #050a06 screen inside a dark bezel with a radial glow, rounded clamp(10–26px) corners, and a green phosphor glow (inset shadow with a faint #7fffba bloom). Over the screen: a radial curved-glass vignette (transparent center to rgba(0,0,0,0.55) edges), scanlines via a 1px/3px repeating gradient plus a 3px aperture grille, multiply-blended; a stepped 4.2s opacity flicker layer; a rolling 22% brightness bar sweeping every 9s. Text is ui-monospace at clamp(12–16.5px), line-height 1.42, with text-shadow glow — classic phosphor #33ff66 with dim tier #1f7a3a, hi tier #d8ffe4.

On load, a boot sequence types itself out character by character (a rAF per-character accumulator, ~400–700 cps per job): ROM monitor version, copyright, memory test "64K OK", video "P1 PHOSPHOR, 80x24", keyboard "84-KEY, BUCKLING SPRING", serial, tape drive, font bitmaps, mounting /gallery, phosphor decay check, then "WELCOME, OPERATOR. THE MACHINE IS YOURS." — Enter or Space skips the ritual and flushes everything instantly. Then a prompt line appears: "operator@t84:~$ " followed by a blinking block caret (1.06s steps blink). All keyboard input drives the buffer (80 chars max); Enter commits and executes; ArrowUp/Down walk a 60-entry history; TAB autocompletes against the command list (unique match completes; multiple matches echo options and extend the longest common prefix); Ctrl+L clears; Ctrl+C shows ^C and a fresh prompt; a hidden opacity-0 input shim focuses on touch devices.

Commands (typed responses render per-character): HELP prints an aligned two-column index; ABOUT tells the machine's story; GALLERY prints an ASCII room index of a 100-room gallery with dotted leaders (01 aurora-glass … 10 terminal-84 — "you are here") and a note that 90 rooms remain dark; MATRIX toggles a canvas glyph-rain overlay (katakana + hex glyphs falling in three depth layers, colored to match the theme, own cancellable rAF); THEME phosphor|amber swaps the entire palette via a body class (amber #ffb000 with matching glows) and updates the bezel button and status line; LISTEN toggles a 60Hz+120Hz sine "mains hum" (WebAudio, gain ramped in over 1.2s, only ever user-initiated); STATUS prints diagnostics (tube chemistry, scrollback lines, history count, rain state, hum state); CLEAR wipes the screen with a wink; WHOAMI, DATE, ECHO do the honest things; SUDO gets the sudoers joke with a curator-report twist; and KONAMI is the easter egg — it prints the code and "TERMINAL/84" as large ASCII block letters plus an "achievement unlocked: PHOSPHOR WHISPERER" line. Unknown commands get "command not found" in red-tinted text with a patient suggestion.

Bottom power strip inside the bezel: a blinking lamp, "TERMINAL/84", a centered status line ("phosphor p1 · 80×24 · ready", winking through tube-warm/idle states every 9s), and two bordered buttons — "HUM: OFF/ON" (fills solid when on) and "AMBER/PHOSPHOR" theme toggle. A 220-line scrollback cap, custom thin phosphor scrollbar, phosphor selection color, focus-visible outlines, reduced-motion kills flicker/roll/blink while the teletype prints instantly. No network, no images — the cathode is CSS, the rain is canvas, the hum is math.
