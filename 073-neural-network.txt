TITLE: Synapses
DESCRIPTION: A glassy neural-network laboratory on a deep lab-blue canvas. A 4-5-4-1 feed-forward network is drawn live: nodes are cyan-and-violet rings whose interiors fill like dials with their activation, and every synapse is a quadratic curve whose thickness is the magnitude of its weight and whose colour is green for positive, coral for negative, with a draggable joint at each edge midpoint. Firing an input sends luminous pulses cascading layer by layer, weighted brightness carried by the signals, the final activation dial reading out beside the output node. A gradient-descent panel animates real backprop training on a chosen truth set (XOR, OR, AND, Majority) while an amber loss curve descends in a mini instrument plot; every edge re-renders as its weight shifts. Mono labels, a serif masthead, glass panels, LED pips and hairline grids complete the bench.
TECHNIQUES:
- Canvas 2D network renderer: quadratic-bezier synapses with weight-mapped stroke width and sign-mapped colour, activation dials drawn as arc fills inside each node, radial-gradient pulse comets travelling the curves
- Real backpropagation (chain rule through two hidden layers, sigmoid derivatives, per-layer weight updates) executed in small batches queued between frames so the UI never stalls
- Editable weights: each edge midpoint is a draggable handle that bends the curve (clamped) and interpolates the weight toward the bend, instantly recolouring and re-weighting the synapse
- Instrument styling: glassmorphism panels (backdrop-filter blur, hairline borders, inset shadows), loss plot on its own canvas with gridlines, area fill and tabular-nums metadata, LED pips that light during training
- Cascaded signal choreography: per-layer pulse delays make the cascade readable; edge and node glow decay exponentially after each fire
- Dataset glyphs rendered as inline SVG truth-table bar charts; keyboard shortcuts (1-4 fire inputs, T toggles training); reduced-motion still frame with functioning training
INTERACTION:
- Click x1-x4 (or press keys 1-4, or click the input nodes on the canvas) to fire that input and watch the signal cascade layer by layer with weighted brightness
- Drag any joint on an edge up or down: the curve bends and the weight follows (target derived from bend), recolouring the synapse in real time
- Press Train to run gradient descent on the selected truth set — watch the amber loss curve descend and every edge re-render as its weight shifts; press Stop to pause; Reweight reseeds all weights
- Choose a truth function from the four SVG dataset tiles (XOR, OR, AND, Majority); the loss history resets for a fresh descent
- Bias current and learning-rate sliders retune the network live; the readout panel reports the last signal vector, the prediction, and the truth with a check or cross; training keeps running while the tab is visible and pauses when hidden
PROMPT:
Create a single self-contained HTML page titled "SYNAPSES — A Neural Network Laboratory". Mood: a beautifully lit machine-learning bench — dark, glassy, precise. Palette: lab background #0d1117 with faint cyan/violet radial ambience, glass panels rgba(22,32,44,.66) with 1px hairline borders rgba(110,168,254,.16), nodes cyan #22d3ee and violet #a78bfa, positive weights green #4ade80, negative weights coral #fb7185, loss amber #fbbf24, text #dbe7f3. Typography: serif masthead "SYNAPSES" in wide letterspaced caps with the "AP" in cyan; everything else ui-monospace in small caps with wide tracking.

Layout: a masthead row ("SYNAPSES · perceptron bench · 4-5-4-1 · handle every weight by hand"), then a two-column grid: left, a large bordered glass stage holding the network canvas with a status chip top-left ("IDLE · fire an input to see the signal travel") and a faint hint line bottom-left; right, a scrollable instrument stack of four glass panels: FIRE AN INPUT (four x-subscript buttons plus a bias-current slider), GRADIENT DESCENT (a mini loss-curve canvas with epoch/loss metadata, TRAIN/REWEIGHT buttons, a learning-rate slider), TRUTH SET (four tiny SVG truth-table tiles for XOR, OR, AND, Majority), and READOUT (last signal, prediction, answer with ✓/✗).

The network: 4 input nodes, 5 then 4 hidden nodes, 1 output node, laid out in four columns on the canvas. Every synapse is a quadratic bezier from node to node through a midpoint joint. Stroke thickness maps |w| (0.8px to 5px); colour maps sign (green positive, coral negative) with opacity scaling magnitude; a small joint dot marks each editable midpoint. Nodes are dark rings with a pie-fill arc showing their current activation (cyan below 0.5, violet above), a soft radial glow while energised, and mono value labels beside input and output nodes. Faint gridlines and column labels INPUT/HIDDEN/HIDDEN/OUTPUT dress the stage.

Signature moment: press x1 — a white-cored comet pulse (green or coral halo by weight sign) travels each first-layer synapse simultaneously, the first hidden nodes light up and fill their dials, then the second layer's pulses follow half a beat later, then the output — the whole cascade readable as travelling light. Drag any joint: the curve bends like a wire under a finger and the synapse's colour and thickness retune live.

Training: press TRAIN and a real backprop loop runs in 12-step batches (~every 40ms) on the selected truth set with the chosen learning rate; the amber loss curve draws a descending polyline with an area fill and a glowing endpoint dot, the epoch counter turns over, and every edge visibly re-renders as its weights change — the network literally rewires itself on screen. REWEIGHT reseeds all weights with a flash. Switching truth sets resets the history.

Engineering: one style block, one script block, zero external resources, system fonts, custom selection and scrollbar styling, pointer capture for drags, devicePixelRatio-capped canvas, one requestAnimationFrame loop paused on tab-hide, responsive single-column layout under 880px, and a reduced-motion path that draws a still network while keeping training functional.
