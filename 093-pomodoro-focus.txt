TITLE: DEEP WORK
DESCRIPTION: A pomodoro timer with editorial grit — a broadsheet ledger rather than an app. The hero is a giant tomato-red session ring (#d94141) around oversized system-ui-900 numerals with hard offset shadows, mode tabs (Focus 25 / Break 5 / Long 15), Begin/Hold button with brutalist press physics, tick and rain toggles, and four round-dots. A 7-day week strip logs completed focus sessions (persisted weekly), the task ledger strikes lines through finished promises with an animated tomato rule, and a serif annotation explains the house rules. When a focus round completes, a synthesized harmonic bell rings (five detuned partials) and the next break auto-starts; entering any break flips the entire palette to deep green (#0f2a24 stage, #7fd1b3 ring) with rain ambience fading in if enabled. Subtle square-wave ticking marks each second when armed.
TECHNIQUES:
- Timestamp-based timer (endAt = Date.now() + remain) immune to background throttling; rAF render loop updates numerals, SVG ring stroke-dashoffset (r=92 circle), document title, and fires per-second tick blips on whole-second changes
- Bell synthesis: five sine partials (E5 base ×0.5/×1/×2.01/×2.98/×4.16) with fast attack and 1.1–3.8s exponential decays; two-note chimes for mode changes and task strikes
- Rain ambience: looped pink-tinted noise buffer through highpass→lowpass chain with 1.6s gain swell; fades in only when rain is armed and renews on each break entry
- Palette flip via body.breakmode custom properties (paper→deep green, ink→cream, tomato→#7fd1b3, highlighter stays #ffd166) with .8s color transitions
- Strike-through animation: absolutely-positioned 2px tomato rule scaling X from 0→1 with cubic-bezier(.7,0,.3,1) on task completion
- Week strip: Monday-anchored 7-slot grid, ISO week number stored in localStorage with weekly rollover and try/catch fallback; today's cell inverted with a TODAY tag
INTERACTION:
- Press Begin (or Space) to start the ring draining; Hold pauses with remaining seconds announced in the footer; Reset (R) refills, Skip (S) advances to the sensible next mode
- Four completed focus rounds automatically route to the 15-minute long rest and refill the dots; the bell marks every completion
- Focus/Break/Long tabs switch modes instantly, flipping the whole page palette green on rest modes
- Tick toggle adds a quiet square-wave second mark; Rain toggle fades in the ambience (it returns on every break while armed)
- Click tasks to strike them (animated line, two-note chime); file new promises via the underlined italic input; hover reveals the × to remove; week strip and counts persist between visits
